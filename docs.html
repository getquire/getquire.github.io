Quickstart

Four minutes, three calls.

  1. 1. Create a workspace key in Settings → API. Keys are scoped to a workspace and inherit that workspace's permissions.
  2. 2. Connect a source. OAuth connectors return a redirect URL; storage connectors take a role ARN.
  3. 3. Ask a question. You get an answer plus a citations array with document, span and version.

Indexing is asynchronous. Poll GET /v1/sources/:id or subscribe to the source.indexed webhook — the first sync of 100k documents takes about 20 minutes.

Ask a question

curl https://api.margin.ai/v1/query \
  -H "Authorization: Bearer $MARGIN_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "question": "Why did EU churn spike in Q2?",
    "sources": ["src_drive_9f2", "src_zendesk_11a"],
    "on_insufficient_evidence": "refuse"
  }'

Response

{
  "answer": "Two causes. The May billing migration
    failed for 340 SEPA customers [1], and German
    residency landed before the feature shipped [2].",
  "citations": [
    {
      "n": 1,
      "document_id": "doc_8812",

}
Reference

Endpoints

REST, JSON, cursor pagination. Streaming responses over SSE where it makes sense.

MethodPathDoes
POST/v1/queryAsk a question. Returns answer, citations, conflicts, confidence.
POST/v1/query/streamSame, over SSE. Citations arrive as they are resolved.
GET/v1/searchRetrieval without generation. Ranked spans, no model call.
GET/v1/sourcesList connected sources with sync state and document counts.
POST/v1/sourcesConnect a source. Returns an OAuth URL or validates credentials.
POST/v1/documentsPush a document directly, for systems we have no connector for.
GET/v1/documents/:idMetadata, version history and parsed structure.
POST/v1/agentsCreate an agent from an instruction, a trigger and a destination.
POST/v1/agents/:id/runRun now, ignoring the schedule.
GET/v1/traces/:idFull trace: retrieval, reranking, model calls, cost.
POST/v1/webhooksSubscribe to answer.created, agent.completed, source.indexed.

Agent definition

{
  "name": "Monday competitor brief",
  "instruction": "Summarize what changed for our
     tracked competitors in the last 7 days.
     Cite every claim. Max 400 words.",
  "trigger": { "type": "schedule", "cron": "0 7 * * 1" },
  "sources": ["src_drive_9f2", "src_web_track_2"],
  "destination": { "type": "slack", "channel": "#market-intel" },
  "approval": "first_10_runs"
}

Errors

{
  "error": {
    "type": "insufficient_evidence",
    "message": "No source supports an answer.",
    "nearest": ["doc_4410", "doc_7781"]
  }
}

insufficient_evidence is a 200 by default, because it's a valid answer. Set on_insufficient_evidence: "error" if you'd rather branch on a 422.
