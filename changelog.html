Changelog

Everything that changed.

Including the removals and the regressions. A changelog that only lists additions is marketing with dates on it.

3.0.0 · Major12 August 2026

Margin 3.0 — disagreement detection

The big one. Answers now flag when two sources support incompatible claims instead of silently picking the higher-ranked span.

  • Added — conflict objects in every answer and API response, with both sources shown
  • Added — 8 connectors: Airtable, Linear, Miro, Figma, Intercom, Front, Coda, Dropbox Paper
  • Added — sub-second first token on warm indexes (median 890ms, from 1.4s)
  • Changed — confidence is now calibrated against held-out human labels rather than model self-report
  • Removed — the "creative" answer mode. It was used by 0.4% of sessions and produced 60% of our complaints
2.8.0 · Minor29 July 2026

Agent approval workflows

  • Added — agents that act outside the workspace now require approval for their first ten runs by default
  • Added — per-agent cost ceilings with a hard stop, not a warning email
  • Fixed — scheduled agents in UTC+13 ran a day early. Affected two workspaces, both notified before we shipped the fix
2.7.2 · Patch15 July 2026

SharePoint permission edge case

This was a security-relevant fix. Documents inheriting permissions from a deleted parent site could be retrieved by users who had lost access. No customer was affected — we found it in our own red-team suite — but the write-up is in the security portal.

  • Fixed — orphaned-inheritance documents are now excluded until re-resolved
  • Added — a nightly permission reconciliation job across all sources
2.7.0 · Minor1 July 2026

Table parsing rewrite

  • Changed — merged cells, multi-row headers and footnote markers now survive parsing. Attribution accuracy on table questions went from 74% to 96%
  • Added — GET /v1/documents/:id returns parsed structure so you can see what we saw
  • Known issue — rotated tables in scanned PDFs still fail about one time in six. Working on it
2.6.0 · Minor10 June 2026

MCP server, and a pricing change in your favor

  • Added — npx @margin/mcp exposes your library as a tool to any MCP client
  • Changed — removed the per-query overage on Team. It was small, but it changed how people used the product, which is worse than the revenue was good
  • Added — Israel region (il-central-1)
2.5.0 · Minor20 May 2026

Trace export

  • Added — SIEM streaming to Splunk, Datadog and generic webhook
  • Added — replay any agent run from any step
  • Fixed — citations pointing at a superseded version when a document changed mid-query

Older releases

Everything back to 1.0 lives in the in-app changelog, and the API-specific changes are mirrored in the docs. Breaking API changes get 12 months notice and an email to every key owner.
